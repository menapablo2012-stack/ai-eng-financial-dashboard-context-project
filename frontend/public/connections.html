Cómo se conecta el dashboard financiero

Este mapa sigue los puntos de entrada y el recorrido real de los datos: desde el navegador, a través del proxy de Vite, hasta la API FastAPI y de vuelta a los gráficos. No añade ni configura conexiones.

Flujo principal de datos

La pantalla principal solicita movimientos y calcula los indicadores en React.

GET /api/metrics
1 · Navegador

Interfaz local

http://localhost:5173

2 · Entrada frontend

React + Vite

src/main.tsx monta App.tsx.

3 · Petición

Proxy de Vite

App.tsx pide /api/metrics; Vite lo reenvía a backend:8000.

4 · Entrada backend

FastAPI

app/main.py registra el router de app/routes.py.

5 · Respuesta

Datos y visualización

La API devuelve movimientos JSON; React calcula KPI y muestra gráficos.

Servicios y direcciones

Los nombres de servicio se usan en la red de Docker Compose.

Abrir documentación de la API ↗

Frontend · servicio frontend

5173:5173

Vite sirve React. El proxy en frontend/vite.config.ts reenvía las rutas /api a http://backend:8000. En el navegador, la API se solicita con una ruta relativa.

Backend · servicio backend

8000:8000 · 5678:5678

Uvicorn ejecuta FastAPI en el puerto 8000. El puerto 5678 está disponible para debugpy. Docker Compose declara que el frontend depende del backend.

Rutas clave del código

Archivos que conectan la estructura con el flujo anterior.

Frontend

  • frontend/src/main.tsxEntry point: monta la aplicación React.
  • frontend/src/App.tsxSolicita /api/metrics y coordina datos, KPI y gráficos.
  • frontend/src/lib/financial-utils.tsCalcula KPI y agrupa movimientos por mes.
  • frontend/src/components/dashboard/Tarjetas y gráficos que presenta el dashboard.
  • frontend/vite.config.tsConfigura el proxy /api → http://backend:8000.

Backend y composición

  • backend/app/main.pyEntry point FastAPI; registra las rutas.
  • backend/app/routes.pyDefine GET /api/metrics y genera los movimientos simulados.
  • backend/DockerfileInicia Uvicorn y debugpy en el contenedor backend.
  • frontend/DockerfileInicia el servidor de desarrollo de Vite.
  • docker-compose.ymlDefine los servicios, puertos y dependencia del frontend.

Rutas existentes aún no usadas por la pantalla principal

Estas rutas están definidas en el backend, pero App.tsx no las solicita actualmente.

  • GET /api/metrics/facetsOpciones de filtros y rango de fechas.
  • GET /api/metrics/summaryResumen agrupado por día, semana o mes.
  • GET /api/metrics/categories/topCategorías con mayores totales.
  • GET /api/metrics/comparisonComparación entre periodos.
  • GET /api/metrics/alertsAlertas por aumento de gastos.
  • GET /api/metrics/b2b y GET /api/metrics/b2cMovimientos filtrados por segmento.
Importante: no hay base de datos conectada. Los registros de /api/metrics son generados por el backend con una semilla fija. Este mapa es una página estática y no cambia cómo funciona el dashboard.
